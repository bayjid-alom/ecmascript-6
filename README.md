## 📝 ECMAScript 6 (ES6)

> This repository covers important ECMAScript 6 (ES6) concepts and features, including both Basic and Advanced topics, with structured notes and practical examples for learning and practice.

---

### ❔ ECMAScript সম্পর্কে

**ECMAScript** হলো একটি standardized specification, যেখানে scripting language-এর syntax, features এবং behavior-এর নিয়মগুলো নির্ধারণ করা হয়। **JavaScript** হলো ECMAScript standard অনুসরণকারী সবচেয়ে বহুল ব্যবহৃত programming language।

ECMAScript সময়ের সাথে বিভিন্ন edition-এর মাধ্যমে উন্নত হয়েছে এবং প্রতিটি নতুন edition-এ নতুন features ও improvements যুক্ত হয়েছে।

ECMAScript-এর **6th edition**, যার official নাম **ECMAScript 2015**, সাধারণভাবে **ES6** নামে পরিচিত। এটি JavaScript-এর একটি গুরুত্বপূর্ণ update, যেখানে অনেক modern features যুক্ত করা হয়।

---

### ❓ ES6 সম্পর্কে

**ES6 (ECMAScript 2015)** JavaScript-এ অনেক নতুন syntax এবং features নিয়ে আসে, যা code-কে আরও readable, powerful এবং maintainable করতে সাহায্য করে।

এই repository-তে ES6-এর fundamental concepts থেকে শুরু করে advanced topics পর্যন্ত ধাপে ধাপে শেখা ও practice করা হয়েছে।
